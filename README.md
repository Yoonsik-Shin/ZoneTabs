# ZoneTabs

화면 분할 도구(Rectangle 등)로 나눈 **영역마다 탭 바**를 띄워, 그 영역 안에 겹쳐 있는 창끼리만 전환하게 해 주는 macOS 메뉴바 앱.

- 화면에 보이는 부분끼리 비교해 둘 중 작은 창의 70% 이상이 가려지는 창들을 한 영역으로 묶는다(큰 창이 작은 창을 완전히 덮는 경우 포함). 분할 자체는 하지 않으므로 Rectangle과 함께 쓴다.
- 창이 2개 이상 겹친 영역의 오른쪽에 앱 아이콘이 세로로 늘어선 플로팅 바가 뜬다. 아이콘을 클릭하면 그 창이 앞으로 온다.
- 바는 평소에 반투명하고 마우스를 올리면 선명해진다. 바 위치(위/아래/왼쪽/오른쪽), 크기, 평소 불투명도는 메뉴바 아이콘 메뉴에서 조절한다.
- 바 끝의 톱니바퀴 버튼을 누르면 같은 설정 메뉴가 그 자리에서 열린다.
- 바가 창의 버튼을 가리면 바를 끌어서 가장자리를 따라 옮길 수 있다. 옮긴 위치는 기억된다.
- `⌥Tab` / `⌥⇧Tab`: 지금 쓰고 있는 창의 영역 안에서 다음 / 이전 창으로 전환.

## 설치

1. [Releases](../../releases/latest)에서 `ZoneTabs.dmg`를 받아 연다.
2. ZoneTabs를 Applications 폴더로 끌어다 놓는다.
3. 응용 프로그램에서 ZoneTabs를 연다. Apple 개발자 서명이 없는 앱이라 처음에는 열리지 않는다. 시스템 설정 > 개인정보 보호 및 보안 맨 아래의 "그래도 열기"를 누르면 열린다.
4. **손쉬운 사용** 권한을 요청하면 시스템 설정 > 개인정보 보호 및 보안 > 손쉬운 사용에서 ZoneTabs를 켠다. 켜면 자동으로 시작된다.

메뉴바 아이콘 메뉴에서 "로그인 시 자동 실행"을 켜 두면 직접 열 필요가 없다.

### 처음 열 때 "열지 않음" 경고가 뜨면

"완료"를 누르고 터미널에서 아래 명령을 실행한다.

```bash
xattr -dr com.apple.quarantine /Applications/ZoneTabs.app
```

```bash
open /Applications/ZoneTabs.app
```

### 업데이트

메뉴바 아이콘 메뉴(또는 바의 톱니바퀴)에서 **업데이트 확인**을 누른다. 새 버전이 있으면 항목이 "새 버전 설치 후 다시 실행"으로 바뀌고, 누르면 받아서 교체한 뒤 자동으로 다시 실행된다. 실행 직후와 하루에 한 번은 자동으로 확인한다.

버전마다 서명이 달라 예전 손쉬운 사용 권한이 맞지 않으므로, 업데이트 후 다시 실행되면 권한을 한 번 더 허용해야 한다.

### 소스에서 직접 빌드

macOS 13 이상, Xcode 또는 Command Line Tools 필요. 빌드해서 `/Applications`에 설치하고 실행까지 한다.

```bash
bash install.sh
```

**ZoneTabs가 실행 중일 때 `tccutil reset`을 직접 실행하거나 앱 파일을 교체하지 말 것.** 단축키용 이벤트 탭이 권한 없이 남으면 시스템 입력이 멈출 수 있다. `install.sh`는 실행 중인 앱을 먼저 끄므로 안전하다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `Windows.swift` | 손쉬운 사용 API로 창 목록 수집, 창 앞으로 올리기 |
| `ZoneController.swift` | 창을 영역으로 묶기, 탭 바 배치, 전환 로직 |
| `TabBarPanel.swift` | 탭 바 UI |
| `HotkeyTap.swift` | `⌥Tab` 단축키 |
| `AppDelegate.swift` | 메뉴바 항목, 권한 처리 |
| `Updater.swift` | 새 버전 확인과 자체 교체 |
